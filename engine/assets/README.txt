Папка ресурсов игры
====================

Текстуры (24/32-bit BMP, без сжатия):
  floor.bmp  — пол
  wall.bmp   — стены
  cube.bmp   — кубы-препятствия

Если файлов нет, движок рисует процедурные текстуры автоматически.

Музыка (положите один из файлов):
  music.mp3
  music.wav

Управление:
  WASD       — движение
  Мышь       — обзор
  Space / C  — вверх / вниз
  Shift      — бег (пример механики)
  Tab        — показать/скрыть курсор
  Esc        — выход

Добавление механик:
  В main.cpp вызовите game.registerMechanic(...) — см. engine/game.h
